# Index: procedural and terrain-aware road generation (per-paper notes)

Compiled 2026-11-25/26 from opened primary sources; free sources only. Each linked note has the full header (URLs opened), BibTeX, method, terrain inputs, evaluation, verbatim quotes with page numbers, comparability with UrbanMorph's matched-input protocol, and evaluation ideas.

**How the quotes were checked.** Every quote in section 7 of every note was matched by script against the PyMuPDF text of the opened PDF (or the saved abstract for AO items). All matched. A few match only after normalising line-break hyphens or PDF spacing; each note says so.

## Legend

**Access**
- **FT** = full text read.
- **AO** = abstract only.
- **MD** = metadata only.

**Comparable?** = could it run on our matched inputs (same 512 m / 4 m DEM window, water mask, entry points, road classes), and in which comparison.
- **Route** = connector routing between supplied points.
- **Grow** = full network growth.
- **Complete** = completion given arterials.

## Corrections to `docs/M18_LITERATURE.md` found in this pass

- **Nishida et al. 2016.** The validation is qualitative plus timing and "rate of example-based growth". There is **no** quantitative comparison of generated vs real or example networks (M18 said "statistics comparison (n.v. in detail)").
- **Lewis & Crema 2026.** The full text is accessible (Article-in-Press PDF at `https://www.nature.com/articles/s41599-026-09179-4_reference.pdf`), so the paper is **FT**, not AO. The road endpoints are the real roads' origins and destinations (confirmed). Data and code are on Zenodo (doi 10.5281/zenodo.20759996, CC BY 4.0).
- **Galin et al. 2011.** The γ-neighbourhood inequality is typeset reversed relative to the paper's own textual description; see that note.
- **Birsak et al. 2022.** The streetz README defines segment circuity as Euclidean / length; the paper defines it as length / Euclidean.
